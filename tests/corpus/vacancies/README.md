# Vacancy texts

Five adverts, one per field, written for this repository.

They are **not** copies. Each was written after reading real listings on
[arbeitsagentur.de](https://www.arbeitsagentur.de/jobsuche/) for that
occupation, and reproduces their *shape* — the "Ihre Aufgaben" / "Ihr
Profil" / "Wir bieten" blocks, the cue phrases that separate a hard
requirement from a nice-to-have, the way a German advert states a language
level or a licence. The wording is original, because a repository is a
poor place to keep somebody else's advertising copy, and because a fixture
that quotes one employer ages the moment they take the listing down. Two of
the listings consulted while writing these had already returned 410 by the
end of the same session.

What they are for: a paired CV in `../resumes/`, and a test that asserts
the tool's reading of the pair.
